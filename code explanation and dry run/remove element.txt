✅ Deep Interview Notes
1. Question

Given an array nums and a value val, remove all occurrences of val in-place and return the number of remaining elements.

Example:

nums = [0,1,2,2,3,0,4,2]
val = 2

Output (valid part):

[0,1,3,0,4]
2. Observation

Har element delete nahi karna.

Bas jo val ke equal nahi hain unhe array ke front me shift karna hai.

3. Variables
i → Write Pointer

j → Read Pointer
4. Core Logic
j poora array traverse karega.
Agar nums[j] != val
us element ko nums[i] par le aao.
i += 1
Agar equal hai
skip.

Na deletion.

Na extra array.

Ek hi traversal.

9. Time Complexity
O(n)
10. Space Complexity
O(1)
11. Interview Explanation

"I use two pointers. One pointer reads every element, while the other marks the next position where a valid element should be placed. Whenever I find an element different from the target value, I copy it to the write pointer and move the write pointer forward. This modifies the array in-place without using extra space."

12. Common Mistakes

❌ Actually deleting elements inside the loop.

nums.remove(val)

This changes indices and is inefficient.

❌ Using an extra list.

ans = []

Interviewer specifically wants an in-place solution.

❌ Forgetting that only the first i elements are valid.

13. One-Line Revision

Read every element. Write only the valid ones.

14. Pattern Recognition 🧠

Notice the similarity:

Move Zeroes
        ↓
Write all non-zero elements

Remove Element
        ↓
Write all elements != val

Remove Duplicates
        ↓
Write only unique elements
