📘 Deep Interview Notes
1. Question

Find the maximum sum of any subarray of size k.

Example

nums = [2,1,5,1,3,2]
k = 3

Output

9
2. Observation

Window size is fixed.

Every time window moves:

Old Window

↓

One element leaves

↓

One element enters

↓

New Window

No need to calculate the sum from scratch.

3. Variables
window_sum

Stores current window sum.

max_sum

Stores maximum sum found so far.

j

Incoming element.

j-k

Outgoing element.

4. Core Logic

Step 1

Calculate first window sum.

[2,1,5]

↓

8

Step 2

Slide the window.

window_sum = window_sum - outgoing + incoming

Code

window_sum = window_sum - l[j-k] + l[j]

Step 3

Update maximum.

5. Dry Run
[2,1,5,1,3,2]
k=3

First window

[2,1,5]

Sum = 8

Slide

[1,5,1]

8-2+1=7

Slide

[5,1,3]

7-1+3=9

Slide

[1,3,2]

9-5+2=6

Maximum

9

7. Why This Approach?

Instead of recalculating:

2+1+5

1+5+1

5+1+3

1+3+2

We reuse the previous sum.

That's why it's called Sliding Window.

8. Edge Cases
k = 1
[2,5,1]

↓

Maximum element
k = length
Whole array

↓

Single window
All negative numbers
[-5,-2,-8]

Still works.
9. Time Complexity
O(n)
10. Space Complexity
O(1)
11. Interview Explanation

"Since the window size is fixed, I first compute the sum of the first k elements. Then, instead of recomputing each window's sum, I slide the window by removing the outgoing element and adding the incoming element. This reduces the time complexity from O(n×k) to O(n)."

12. Common Mistakes

❌ Recalculating every window.

O(n×k)

❌ Forgetting

max_sum = window_sum

after the first window.

❌ Using

l[i]

instead of

l[j-k]

for the outgoing element.

(Ye mistake tumne khud identify karke fix kar li. 👍)

13. One-Line Revision

Fixed-size window → Remove outgoing element + Add incoming element.

🧠 Sliding Window ka Golden Formula

Ye formula ratna nahi hai, samajhna hai.

window_sum = window_sum - outgoing + incoming

Aur code me:

window_sum = window_sum - l[j-k] + l[j]

Yahan:

l[j-k] → Window se bahar jaane wala element
l[j] → Window me andar aane wala element
Ab tum khud code complete karo.
