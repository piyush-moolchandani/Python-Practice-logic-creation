Interview Statement

We use while instead of if because removing one character does not guarantee that the duplicate is removed. We keep shrinking the window until the current character becomes unique inside the window.

Interview Explanation (30 Seconds)

"I use a variable-size sliding window with two pointers. The right pointer expands the window, while a set stores all unique characters currently inside the window. If the incoming character is already present, I repeatedly move the left pointer and remove characters from the set until the duplicate is removed. Once the window becomes valid again, I add the current character and update the maximum window length. Since both pointers move only forward, the overall time complexity is O(n)."

One-Line Revision

Expand the window using right; whenever a duplicate appears, keep shrinking the window with left until it becomes unique again, then update the maximum window length.
