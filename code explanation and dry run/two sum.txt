📘 Pair Sum (Two Sum)
1. Question

Given an array of integers and a target value, find the two numbers whose sum equals the target.

Example:

nums = [2,7,11,15]
target = 9

Output:

Indices = [0,1]

Because

2 + 7 = 9

13. Interview Explanation

"Instead of comparing every pair, I calculate the complement (target - current) for each element. I use a HashMap to store previously visited values with their indices. If the complement already exists in the HashMap, I've found the answer immediately. Otherwise, I store the current value and continue. This reduces the time complexity from O(n²) to O(n) while using O(n) extra space."

14. Common Mistakes

❌ Storing

d[index] = value

Instead of

d[value] = index

❌ Searching after storing in the wrong order.

❌ Forgetting to stop after finding the pair.

❌ Using nested loops instead of a HashMap.

15. One-Line Revision

"For every number, calculate the complement (target - current). If the complement already exists in the HashMap, return both indices; otherwise, store the current value with its index."

🧠 Pattern Recognition (Most Important)

Ye question tumhe ek naya DSA pattern sikhata hai:

Reverse Array → Two Pointers
Move Zeroes → Read Pointer + Write Pointer
Merge Two Sorted Arrays → Two Pointers on Two Arrays
Pair Sum (Two Sum) → HashMap + Complement

Interview me agar koi question aaye jisme line ho:

"Find a pair...", "Two numbers...", "Target sum..."

To sabse pehle dimaag me Complement + HashMap wala pattern aana chahiye. Yahi is problem ka sabse bada takeaway hai. 💯
