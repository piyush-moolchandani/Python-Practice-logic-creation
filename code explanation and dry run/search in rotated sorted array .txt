Ek line ka mantra 🔥

"Pehle sorted half pakdo, phir dekho target us sorted half ke range me hai ya nahi."

Normal Binary Search me tum sirf mid vs target dekhte the.

Rotated Binary Search me:

mid → sorted half → target range → direction

Ye pattern interview tak yaad raha, to question khud reconstruct kar loge.

agar interviewer bole explain internal working toh kya bolu

Haan bhai, agar interviewer bole “Explain the internal working of Search in Rotated Sorted Array”, to code line-by-line nahi bolna. Approach + decision making explain karni hai.

Tum roughly ye bol sakte ho:

“Since the array is rotated, the complete array is not sorted, so normal binary search cannot be directly applied. But in every iteration, at least one half of the current search space is sorted.

I first calculate the middle element. If it is equal to the target, I return its index. Otherwise, I check whether the left half is sorted by comparing l[left] and l[mid].

If the left half is sorted, I check whether the target lies within the range of that sorted half. If it does, I search on the left; otherwise, I discard the left half and search on the right.

If the left half is not sorted, then the right half must be sorted. I check whether the target lies in the sorted right half. If it does, I search on the right; otherwise, I search on the left.

I repeat this until I find the target or the search space becomes empty. Therefore, the time complexity is O(log n) and space complexity is O(1).”

Agar interviewer bole: “Why does this work?”

Ye line maarna 🔥:

“Rotation breaks the sorted order at one point, so at any midpoint, one of the two halves still remains completely sorted. I use that sorted half to determine which half can be safely discarded.”

Aur agar example maange:
[4,5,6,7,0,1,2]
target = 0

Bolna:

“Initially middle is 7. The left half [4,5,6,7] is sorted, but 0 doesn't lie in its range, so I discard that half and move right. Now I get [0,1,2], where the left half is sorted and the target lies in its range. I continue left until I find 0.”
