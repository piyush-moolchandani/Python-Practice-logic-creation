🧠 Ab Sabse Important Logic

Tumhara doubt tha:

if dq and l[j-k] == dq[0]:

Iska matlab ye nahi hai ki:

"Negative mila to remove."

Iska matlab hai:

"Jo element window se bahar gaya hai, agar wahi hamara current first negative tha, tabhi usse deque se hatao."

Agar bahar gaya element negative hi nahi tha:

12

to deque ko chhedna hi nahi.

Agar bahar gaya negative tha lekin first negative nahi tha, wo case aa hi nahi sakta, kyunki deque hamesha window ke negatives ko order me rakhta hai. Agar koi negative window se bahar ja raha hai, wo sabse pehle front par hi aayega.

Interview Notes
Question

Find the first negative integer in every window of size k.

Observation

Hume poori window nahi dekhni.

Sirf window ke negative numbers maintain karne hain.

Data Structure

deque

Kyun?

append() → O(1)
popleft() → O(1)
Front access → O(1)
Variables
dq

Window ke negative numbers ko order me store karta hai.

ans

Har window ka answer.

j

Incoming element.

j-k

Outgoing element.

Core Logic
First window ke negatives deque me store karo.
Front answer hai.
Window slide karo.
Agar outgoing element deque ke front ke equal hai, popleft() karo.
Agar incoming negative hai, append() karo.
Deque ka front answer hai; agar deque empty hai to 0.

Time Complexity
O(n)

Har negative element ek baar deque me aata hai aur ek baar hi nikalta hai.

Space Complexity
O(k)

Worst case me window ke saare elements negative ho sakte hain.

Common Mistakes

❌ if l[j-k] == dq[0]:

Isse pehle dq empty hai ya nahi check na karna.

if dq and l[j-k] == dq[0]:

✅ Ye safe version hai.

One-Line Revision

Deque me window ke negative numbers rakho. Agar first negative window se bahar jaye to popleft(), aur naya negative aaye to append(). Front hi answer hai.
