Bilkul bhai ❤️ Is baar ekdum zero se, line-by-line + har iteration me i/j, dq, ans sab track karenge. Ye code actually simple hai, bas index wali thinking thodi confusing hai.

Tumhara code:

from collections import deque 

l = [12, -1, -7, 8, -15, 30, 16, 28] 
k = 3 

dq = deque() 
ans = [] 

for i in range(k): 
    if l[i] < 0: 
        dq.append(i) 

ans.append(l[dq[0]] if dq else 0) 

for j in range(k, len(l)): 
    if dq and j-k == dq[0]: 
        dq.popleft() 

    if l[j] < 0: 
        dq.append(j) 

    ans.append(l[dq[0]] if dq else 0) 

print(ans)
1. Problem ko ek baar yaad karo
l = [12, -1, -7, 8, -15, 30, 16, 28]
k = 3

Har 3 elements ki window me first negative chahiye.

Windows:

[12, -1, -7]       → -1
[-1, -7, 8]        → -1
[-7, 8, -15]       → -7
[8, -15, 30]       → -15
[-15, 30, 16]      → -15
[30, 16, 28]       → 0

Expected:

[-1, -1, -7, -15, -15, 0]
2. deque
dq = deque()

Deque ko hum negative numbers ke indexes store karne ke liye use kar rahe hain.

⚠️ Values nahi, indexes.

For example:

l = [12, -1, -7]
       ↑   ↑
       1   2

Deque:

[1, 2]

Matlab:

index 1 → l[1] = -1
index 2 → l[2] = -7

Why index?

Because window slide hone par hume pata lagana hai ki koi negative window se bahar gaya ya nahi.

Ab sabse confusing line samjho
if dq and j-k == dq[0]:

Isko 2 parts me padho:

Part 1:
dq

Kya deque empty nahi hai?

Part 2:
j-k == dq[0]

j-k = jo index window se bahar ja raha hai

dq[0] = deque me sabse purana negative index

So poori line:

"Agar deque khaali nahi hai aur jo element window se bahar ja raha hai wahi deque ke front wala negative hai, to use hata do."

Ek aur SUPER important point

Tum soch sakte ho:

j-k outgoing index kyun hai?

Example:

k = 3

Jab:

j = 4

Current window:

indexes: 2  3  4

Isse pehle wali window:

indexes: 1  2  3

To jo bahar gaya:

index 1

Aur:

j-k
= 4-3
= 1

Exactly. 🔥

Aur dq[0] hi kyun?

Kyuki deque me negative indexes order me hain:

[1, 2, 4]

Sabse left:

dq[0] = 1

means sabse pehla/oldest negative.

Isliye:

l[dq[0]]

gives current window ka first negative.

Final mental model 🧠

Is question me bas ye 4 steps hain:

1️⃣ Negative mila?
   ↓
   uska INDEX deque me daalo

2️⃣ Window slide hui?
   ↓
   outgoing index deque ke front me hai?
   ↓
   YES → popleft()

3️⃣ deque empty hai?
   ↓
   YES → 0

4️⃣ deque empty nahi?
   ↓
   l[dq[0]]

Aur sabse important:

dq me VALUES nahi hain
dq me INDEXES hain
dq[0]          → index
l[dq[0]]       → actual negative value

Bas ye distinction pakad liya bhai, to poora question tumhara hai. ❤️
