l = [1,0,2,0,3,0]
i = 0

for j in range(len(l)):
    if l[j] != 0:
        if i != j:
            l[i], l[j] = l[j], l[i]
        i += 1

print(l)

Question

Given an array, saare non-zero elements ka order same rakhna hai aur saare zeroes ko end me le jana hai.

Example:

Input:
[1,0,2,0,3,0]

Output:
[1,2,3,0,0,0]
Sabse pehle observation

Hum zero ko move nahi karenge.

Ye sabse important point hai.

Hum sirf non-zero elements ko unki correct position par laayenge.

Jab non-zero aage aa jayenge, zero automatically peeche chale jayenge.

Interview me ye line bolna:

"Instead of pushing zeroes to the end, I pull non-zero elements to the front."

Ye line kaafi strong impression deti hai.

i != j Optimization

Suppose array hai:

[1,2,3,0]

Har non-zero already correct position par hai.

Agar hum har baar swap kare:

l[0], l[0] = l[0], l[0]

Fir

l[1], l[1] = l[1], l[1]

Fir

l[2], l[2] = l[2], l[2]

Ye unnecessary operations hain.

Isliye pehle check karte hain:

Kya i aur j alag hain?

Agar haan,

Swap.

Agar nahi,

Swap skip.

Agar interviewer puche:

"Why did you use two pointers?"

Tum confidently bol sakte ho:

"j poore array ko scan karta hai aur i next valid position maintain karta hai jahan agla non-zero element rakhna hai. Isse hum array ko ek hi pass me in-place modify kar dete hain, bina extra space use kiye."

Ek line me poora concept (Notes ke liye)

j scans every element. i always points to the next position where the next non-zero element should be placed. When a non-zero is found, it is moved to index i (only if needed), then i is incremented. Zeroes are ignored, so they naturally accumulate at the end.
