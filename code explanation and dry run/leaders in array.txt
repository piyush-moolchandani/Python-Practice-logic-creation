📘 Leaders in Array – Interview Notes
1. Question

Given an array, find all the leaders.

A leader is an element that is greater than every element to its right.

Example

[16,17,4,3,5,2]

Answer

[17,5,2]

6. Core Logic
Last element is always a leader.
Store it.
Keep max_right.
Traverse from right to left.
If current > max_right
Add to answer.
Update max_right.
Reverse the answer.

10. Interview Explanation

"Since a leader only depends on the elements to its right, I traverse the array from right to left while maintaining the maximum element seen so far (max_right). If the current element is greater than max_right, it is a leader. I store it, update max_right, and finally reverse the result because leaders were collected from right to left."

11. One-Line Revision

"Traverse from right to left, maintain max_right, add elements greater than max_right, then reverse the answer."
