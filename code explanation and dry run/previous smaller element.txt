Previous Smaller Element — Deep Notes
1. Question

Given:

l = [4, 5, 2, 10, 8]

Har element ke left side me nearest/pehla smaller element find karna hai.

4  → -1
5  → 4
2  → -1
10 → 2
8  → 2

Final output:

[-1, 4, -1, 2, 2]

Important:

Hume left side ka sabse chhota element nahi chahiye. Hume current element ke left me sabse paas wala smaller element chahiye.

2. Final Code
l = [4, 5, 2, 10, 8]

stack = []
ans = []

for i in range(len(l)):

    while stack and stack[-1] >= l[i]:
        stack.pop()

    if not stack:
        ans.append(-1)
    else:
        ans.append(stack[-1])

    stack.append(l[i])

print(ans)

Output:

[-1, 4, -1, 2, 2]
3. Left → Right kyun?

NGE vs PSE — Confusion mat karna

Tumne ab dono kiye hain:

	Next Greater	Previous Smaller
Answer kidhar chahiye?	Right	Left
Traverse	Right → Left	Left → Right
Remove	smaller/equal	bigger/equal
While	top <= current	top >= current
Empty stack	-1	-1
Not empty	stack[-1]	stack[-1]

Ye comparison kaafi useful hai.

Complexity

Har element maximum ek baar push aur ek baar pop hota hai.

Time Complexity = O(n)
Space Complexity = O(n)

Nested while dekhkar O(n²) mat sochna.
