10. Interview Explanation

"First, I preprocess the string by keeping only alphanumeric characters and converting everything to lowercase. Then I use the standard two-pointer palindrome check. If any pair of characters differs, I return False immediately; otherwise, if all pairs match, it's a valid palindrome."
